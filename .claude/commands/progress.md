# 명령어: /progress

사용자가 전달한 진행 상황을 바탕으로 `docs/ROADMAP.md`의 체크박스를 업데이트합니다.

## 사용법

```
/progress Phase 0 완료, Phase 1 메인 페이지 진행 중
```

## 프로세스

1. `docs/ROADMAP.md` 파일을 Read로 읽는다.

2. `$ARGUMENTS`로 전달된 사용자 입력을 분석한다.
   - "완료", "끝", "다 했" 등의 표현 → 해당 Phase 또는 항목을 완료 처리
   - "진행 중", "하고 있", "작업 중" 등의 표현 → 해당 항목을 진행 중 처리

3. 파일을 Edit 도구로 수정한다.
   - 완료된 항목: `- [ ]` → `- [x]` 로 변경
   - 진행 중인 항목: 항목 텍스트 끝에 `🔄 진행 중` 추가
   - 이미 `🔄 진행 중`이었다가 완료된 항목: `🔄 진행 중` 제거 후 `- [x]` 로 변경

4. 변경된 항목들을 요약해서 사용자에게 알려준다.

## 주의사항
- 사용자 입력과 가장 유사한 항목을 찾아 수정한다.
- Phase 전체를 완료했다고 하면 해당 Phase의 모든 `- [ ]` 항목을 `- [x]` 로 변경한다.
- 애매한 경우 사용자에게 확인한다.
- 반드시 Edit 도구로 수정한다 (Write로 전체 덮어쓰기 금지).
